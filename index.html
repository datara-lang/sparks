How to Publish a Spark via GitHub PR

Sparks is 100% decentralized and static. No developer API tokens or proprietary upload services are required. Submit your package directly via a standard GitHub Pull Request.

STEP 01
Package Your Code

Package your library source files and capabilities.json into a POSIX ustar tarball.

dpm pack
# or manually:
tar -cf mypkg-1.0.0.tar main.dtr capabilities.json
STEP 02
Compute Digest & Sign

Compute the SHA-256 hash of your tarball and sign it with your ed25519 key.

sha256sum mypkg-1.0.0.tar
dpm sign mypkg-1.0.0.tar
STEP 03
Submit Pull Request

Add packages/mypkg/1.0.0.json to the registry repo and submit a PR.

git checkout -b spark/mypkg-1.0.0
git commit -m "feat(sparks): add mypkg 1.0.0"
gh pr create --fill
